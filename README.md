# MegapolisCore — плагин для Minecraft сервера Grand World

## Описание
MegapolisCore — это монолитный плагин для Paper 1.19.2, реализующий огромное количество механик для RPG-сервера с уклоном в экономику, транспорт, бизнесы и социальное взаимодействие.

## Основные возможности
- **Транспортная система**: машины, мотоциклы, лодки, вертолёты с уникальными моделями (CustomModelData), управление W/S/мышь, нитро, топливо, повреждения и взрывы.
- **Бизнесы и организации**: создание бизнесов, казна, сотрудники, банкротство, аукцион.
- **Экономика**: множество валют (рубль, доллар, евро, криптовалюта), банки с кредитами, вкладами, обменом, динамические курсы.
- **Планшет**: единый интерфейс для банка, авторынка, гос. магазина, заданий, кейсов, аукциона, мессенджера, скинов.
- **Скины и трансформеры**: применение скинов через предметы, трансформация в машину с эффектами.
- **Задания**: ежедневные задания (2 обычных + 1 бизнес-задание) с наградами.
- **Локации**: настраиваемые зоны (стоянки, полиция, бизнесы, постоматы, тюнинг-ателье) с автоматическим открытием GUI при входе.
- **Государственный магазин**: покупка предметов по фиксированным ценам.
- **Аукцион**: продажа/покупка предметов между игроками.
- **Мессенджер**: личные сообщения, групповые чаты, непрочитанные.

## Установка
1. Поместите файл `MegapolisCore.jar` в папку `plugins` вашего сервера.
2. Убедитесь, что на сервере установлены зависимости:
   - **Vault** (для экономики)
   - **EssentialsX** (для команд и валюты)
   - **SkinRestorer** (для скинов)
   - **WorldGuard** (для защиты спавна, опционально)
3. Запустите сервер один раз для генерации конфигурации.
4. Отредактируйте `config.yml` под свои нужды (локации, цены, модели транспорта).
5. Перезапустите сервер или выполните `/megapolis reload`.

## Конфигурация
Основной файл — `config.yml`. Ключевые секции:
- `storage`: выбор хранилища (json или mysql).
- `vehicles`: модели транспорта с `model_id`, ценой, характеристиками.
- `tuning`: цены и уровни улучшений.
- `cases`: настройка кейсов и наград.
- `gov_shop`: товары государственного магазина.
- `market_items`: ивентовые предметы.
- `locations`: точки с типами (parking, police, business, postomat, tuning).
